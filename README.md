## 🚀 Mission Overview

**Quantticks Oracle** is a high-performance, zero-trust environmental intelligence platform designed to harmonize orbital thermal anomalies and Fire Radiative Power (FRP) monitoring across NASA and NOAA satellite constellations (MODIS and VIIRS). 

By combining decentralized Parquet storage via Cloudflare R2, analytical acceleration through DuckDB, and a zero-bloat static command center built with Hugo and Plotly.js, the system delivers real-time spatial telemetry within an efficient sliding quota window.

---

## 🛠️ Core Architecture & Tech Stack

* **Data Ingestion & Harmonization Engine:** Automated ingestion and schema harmonization across MODIS (1km) and VIIRS (375m) active fire telemetry feeds[cite: 8].
* **Storage & Analytical Layer:** Cloudflare R2 S3-compatible object storage (`quantticks-nasa-parquet`) coupled with DuckDB for high-speed columnar queries.
* **Data Compression:** ~80.5% data compression ratio achieved via ZSTD-compressed Parquet files.
* **Presentation Layer:** Hugo static site generator paired with Plotly.js for interactive dark-mode maps and distribution charts.
* **CI/CD & Hosting:** GitHub Actions automated workflow deploying directly to Cloudflare Pages on `nasa.quantticks.com`[cite: 7].

---

## ✨ Key Features

1. **Multi-Sensor Harmonization & Separation:** Fully abstracts satellite origins while allowing granular isolation (`MODIS + VIIRS Combined`, `MODIS Only`, `VIIRS Only`) to satisfy advanced spatial evaluation criteria.
2. **Interactive ScatterGeo Mapping:** Zoomable global thermal hotspot map rendering precise latitude, longitude, and Fire Radiative Power (FRP) metrics.
3. **Dynamic Regional & Sensor Filtering:** Real-time filtering across active global regions (Amazon Basin, California, Mediterranean, Newfoundland & Atlantic Canada, Siberia, etc.) with adjustable confidence thresholds.
4. **Client-Side CSV Export:** Instant browser-based filtering and CSV export capabilities for customized telemetry data extraction.

⚙️ Local Development & Pipeline Execution
Clone the Repository:

PowerShell
git clone [https://github.com/code2expert/quantticks-nasa.git](https://github.com/code2expert/quantticks-nasa.git)
cd quantticks-nasa
Configure Environment Variables:

Create a .env file in the root directory containing your Cloudflare R2 credentials:

Code snippet
R2_ACCESS_KEY_ID="your_access_key"
R2_SECRET_ACCESS_KEY="your_secret_key"
Generate Telemetry JSON Payload:

PowerShell
python script/export_dashboard_data.py
Run Local Hugo Server:

PowerShell
hugo server --gc --cleanDestinationDir
Open http://localhost:1313 in your browser.
